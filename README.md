# osirisstudiogames.github.io

GitHub Pages site for oSiRiS Studio — support, privacy policy, and terms of service pages for our apps.

## Structure

- `index.html` — landing page linking to both apps below
- `404.html` — custom not-found page
- `sudoku/` — pages for **Sudoku Master: Classic Logic** (mobile app)
  - `support.html` — support center, account/data deletion instructions
  - `privacy.html` — Privacy Policy
  - `terms.html` — Terms & Conditions
- `vektra/` — pages for **Vektra** (Discord bot)
  - `support.html` — support center, data deletion instructions
  - `privacy.html` — Privacy Policy
  - `terms.html` — Terms of Service
- `app-ads.txt` — required by AdMob for the Sudoku app

Each page is a static, self-contained HTML file (inline CSS, no build step). Favicons (`favicon.png`) are expected at the root and in each app's folder but are not committed here.
