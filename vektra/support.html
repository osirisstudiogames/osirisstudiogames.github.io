Welcome to the oSiRiS Studio support center for the Vektra Discord bot.

Data and Configuration Deletion

Vektra does not require an account beyond your Discord identity. Depending on what you'd like removed:

  1. Translation setup: use /removeconfig in your server to remove one or all translation pairs yourself, at any time.
  2. Hangman stats, points, and language preference: send an email to osirisstudio.games@gmail.com with your Discord user ID, and we will delete the data tied to it within a reasonable time.
  3. Removing the bot entirely: kick Vektra from your server via Discord's server settings; server-level configuration is deleted automatically.

Note: Once deleted, this data cannot be recovered.

Questions or Feedback

Use the /feedback command from within Discord (works in servers and DMs), or email osirisstudio.games@gmail.com.
